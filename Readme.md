# Neural Network Framework in C++

## Overview
This project is a **lightweight Neural Network Framework implemented entirely in C++**, developed to demonstrate the internal working of neural networks without relying on external machine learning libraries. The framework focuses on **core concepts such as forward propagation, backpropagation, loss computation, and gradient descent**, making it ideal for academic learning and foundational AI research.

The project emphasizes **clarity, modular design, and object-oriented programming**, enabling users to understand and extend neural network components at a low level.

---

## Objectives
- Implement neural networks **from scratch in C++**
- Understand mathematical and programmatic foundations of deep learning
- Provide an extensible framework for academic experimentation
- Avoid dependency on high-level ML libraries

---

## Key Features
- Pure **C++ implementation**
- No external machine learning libraries
- Object-Oriented and modular architecture
- Supports:
  - Fully Connected (Dense) Layers
  - Activation Functions:
    - Sigmoid  
    - ReLU  
    - Tanh  
  - Loss Functions:
    - Mean Squared Error (MSE)
    - Cross Entropy
  - Forward Propagation
  - Backpropagation
  - Gradient Descent Optimization
- Tested using the **XOR classification problem**
- Platform-independent compilation

---

## Technologies Used
- **Programming Language:** C++
- **Libraries:** Standard Template Library (STL)
- **Concepts:**  
  - Object-Oriented Programming (OOP)  
  - Neural Networks  
  - Backpropagation Algorithm  
  - Gradient Descent
